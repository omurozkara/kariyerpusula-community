# Contributing

Issues and PRs are welcome for tests, documentation, portability improvements and clearly defined security behaviors.

1. Explain the problem and your proposed behavior. Use synthetic data only.
2. Create a focused branch and test with Node.js 20+ (`npm test`).
3. Include regression tests for changes to permissions, object names or file validation.
4. Never commit secrets, service credentials, real evidence files, CVs, personal information or production logs.
5. Document potentially breaking changes and explain why your new behavior is safe.

The maintainer reviews contributions; no review timeframe is promised. See `SECURITY.md` for private disclosure. By contributing, you agree that your code can be distributed under the MIT license in this repository.
