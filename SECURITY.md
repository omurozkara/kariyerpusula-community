# Security Policy

Version 0.1.x is experimental. No guaranteed response SLA or supported security-release lifecycle exists yet.

**Please do not post exploitable vulnerabilities, private tokens, CVs or other personal data in public issues.** Use GitHub's private vulnerability reporting when enabled, or contact the maintainer privately via their GitHub profile to establish a secure channel. Use synthetic repro steps. Do not test against production systems or real users.

Security-critical changes require regression tests; see the README threat model. This library is a set of policy helpers, not a secure evidence-storage service.
