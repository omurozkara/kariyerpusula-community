# Changelog

## [0.1.0] — Initial experimental release candidate

- Dependency-free policy helpers for evidence attachment authorization.
- Cryptographically random object keys with strict path validation.
- Lightweight file magic-byte checks for four accepted formats.
- Loopback-only test target validation.
- TypeScript declarations, automated Node.js tests, security documentation.

**Status:** This is an experimental source release candidate. It is not published to npm and does not claim outside adoption or maintainers.
